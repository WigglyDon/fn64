# Legal And Private Input Audit

Inputs used:

- public Nintendo RSP documentation;
- pinned public decompals N64-IPL source and RCP definitions;
- repository-owned generated cold-x105 fixtures;
- independent public synthetic instruction words and byte patterns.

Not read, copied, executed, or packaged:

- a commercial cartridge;
- a private/proprietary PIF image;
- user-task microcode or user-derived IMEM/DMEM/RSP words;
- a complete public x105 RSP program;
- a complete 4096-byte memory dump;
- retired C++ product code.

The evidence records only bounded words, ranges, digests, and anchors required
to prove the represented seam.
