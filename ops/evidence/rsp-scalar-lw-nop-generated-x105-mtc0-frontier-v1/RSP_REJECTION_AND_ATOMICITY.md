# RSP Rejection And Atomicity

Complete-state comparisons cover unavailable Lw base, misalignment,
unavailable or malformed DMEM knowledge, other scalar loads and stores,
nonzero SLL, selected fetch/single-step boundaries, and the Mtc0 frontier.

Every rejection preserves processor turn, run-start/task facts, PCs, RSP
count, scalar/vector/accumulator state, last instruction, SP control and DMA,
DMEM/IMEM, MI, CPU/COP0 state and counts, VI, devices, memory, cartridge,
reservations, and host state. No CPU fallback occurs.
