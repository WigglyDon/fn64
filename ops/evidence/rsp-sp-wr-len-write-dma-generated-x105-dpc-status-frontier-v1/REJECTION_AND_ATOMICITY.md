# Rejection and atomicity

Focused proofs cover unavailable scalar source, malformed encoding, unsupported
control destinations, absent addresses, record exhaustion, source
unavailability, opaque IMEM truth, unsupported source wrap, destination range
failure, fetch failure, selected single-step, and the DPC_STATUS frontier.

All pre-commit failures compare equal to a complete pre-step snapshot. Selected
RSP rejection receives no CPU fallback.
