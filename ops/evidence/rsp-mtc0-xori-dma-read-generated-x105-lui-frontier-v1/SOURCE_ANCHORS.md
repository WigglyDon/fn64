# Source Anchors

- [Nintendo Ultra64 RSP Programmer's Guide](https://ultra64.ca/files/documentation/silicon-graphics/SGI_Nintendo_64_RSP_Programmers_Guide.pdf): RSP COP0 transfers, scalar Xori, SP DMA alignment and length/count/skip fields.
- [Pinned public x105 IPL3](https://github.com/decompals/N64-IPL/blob/928f59089c18a95cbffa59938a18fa6032c5d78c/src/ipl3.s): bounded local sequence `0x018..0x028`.
- [Pinned RCP definitions](https://github.com/decompals/N64-IPL/blob/928f59089c18a95cbffa59938a18fa6032c5d78c/include/PR/rcp.h): SP register indices.

Only five necessary RSP words and eight necessary RDRAM bytes are recorded.
